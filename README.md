# 🏠 House Price Prediction

This repository contains a Jupyter Notebook that predicts house prices using machine learning techniques. It walks through the steps of data preprocessing, feature engineering, model selection, and evaluation.

## 📁 Files

- `HousePricePrediction.ipynb`: Main notebook that performs exploratory data analysis and builds a predictive model.
- `README.md`: Documentation for the project.

## 📌 Project Objectives

- Understand the factors that influence house prices.
- Preprocess and clean the housing dataset.
- Train and evaluate regression models to predict house prices.
- Interpret the model results.

## ⚙️ Technologies Used

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
